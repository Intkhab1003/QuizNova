## 📋 Overview

**QuizNova** was developed as the **Week 3 Internship Task** for the Webora Tec Frontend Development program. The objective was to build a complete, robust web application from scratch without relying on any external frameworks or libraries (No React, No Bootstrap). It demonstrates a strong command of DOM manipulation, array methodologies, and modern CSS design principles.

## ✨ Key Features

*   **🎨 Glassmorphism UI**: A premium, frosted-glass design system with subtle 3D hover states and smooth animations.
*   **🌓 Light/Dark Theme**: Built-in theme toggling utilizing CSS variables for seamless transitions.
*   **⏱️ Active Countdown Timer**: A 10-minute timer that visually warns the user at the 1-minute mark and auto-submits upon completion.
*   **🧠 Dynamic State Management**: Tracks user progress, selected answers, and score in real-time across multiple screens.
*   **📊 Comprehensive Results Dashboard**: Calculates percentages, provides contextual feedback, and categorizes answers (Correct, Incorrect, Unanswered).
*   **🔍 Answer Review System**: Allows users to review their performance with detailed explanations for the correct answers.
*   **🎵 Web Audio API Integration**: Zero-dependency synthesized sound effects for interactions (with mute toggle).

## 🛠️ Tech Stack

*   **Structure:** HTML5 (Semantic elements, accessibility considerations)
*   **Styling:** CSS3 (Custom Variables, Flexbox, Grid, Media Queries, Keyframe Animations)
*   **Logic:** Vanilla JavaScript (ES6+, Event Delegation, Timers, Web Audio API)

## 💻 How to Run Locally

Since this project uses vanilla web technologies, no build step or package installation is required.

1.  **Clone the repository:**
    ```bash
    git clone [https://github.com/Intkhab1003/QuizNova.git](https://github.com/Intkhab1003/QuizNova.git)
    ```
2.  **Navigate to the project directory:**
    ```bash
    cd QuizNova
    ```
3.  **Run the application:**
    *   Open `index.html` directly in your browser.
    *   *OR* for the best experience, open the project in VS Code and use the **Live Server** extension.
